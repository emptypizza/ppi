# 펍지키우기포지마스터 (RETRO ROYALE)

웹 리메이크 공개 저장소. GitHub Pages에서 바로 플레이할 수 있습니다.

**Play:** https://emptypizza.github.io/ppi/

원작: [gghf.itch.io/ppi](https://gghf.itch.io/ppi)

## 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 마우스 | 조준 |
| 클릭 | 공격 |
| Shift | 급강하 / 스프린트 |

상자 7개를 먹고 초록 웜홀로 탈출하세요. 자기장은 초당 90 데미지입니다.

매치가 끝나면 골드를 받고, 오른쪽 **훈련소**에서 HP/공격/이동/스테미나/운/방치/시작무기를 영구 강화합니다. 포탈 탈출이나 최후의 1인이면 스테이지가 오르고 봇이 강해집니다. 탭을 꺼도 최대 8시간 골드를 받습니다.

## 로컬

브라우저에서 `index.html`을 열면 됩니다.

```bash
python3 -m http.server 8080
# http://localhost:8080
```
